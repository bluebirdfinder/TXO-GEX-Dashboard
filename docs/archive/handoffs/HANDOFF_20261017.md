## 3. 這次學到的架構事實（很重要，別再踩）

| 事實 | 影響 |
|---|---|
| 8000 的戰情室**不是**本資料夾，是 `txo-klines-runner` 的 clone，由排程管理 | 要讓 8000 看到新程式：獨立 worktree 接到最新 main → 推上去（先問）→ 殺 python 進程讓排程重啟同步。**不要自己另開 8000**（會和排程搶埠） |
| `start_live_with_advisor.bat`（已在 main）**不可用** | 它會和排程搶 8000。建議刪掉或改寫成只啟動橋接 |
| runner 的 `git checkout -f -B main origin/main` 不清 untracked／ignored 檔 | 所以 `trading room/brain/`（策略知識庫，gitignore）要**手動複製**到 `txo-klines-runner\trading room\brain\`；知識庫更新後要再複製 |
| Worker 只接受 `bluebirdfinder.github.io`／localhost 來源 | **直接在網址列開 Worker 網址一定看到 `origin not allowed`**。驗證要從戰情室頁面（localhost:8000）的 console 發請求，例如 `await (await fetch(ADX_MTF_API+'?indicator=health')).json()` |
| GitHub Pages 的 `klines_cache.json` 落後（富邦分K只在本機累積，不進 git） | 任何讀 Pages 資料的 Worker 指標都會停在舊K棒；現在 chart／momentum／smc／adx-mtf 都改 POST 本機最新K棒 |
| `data/klines_cache.json`（runner 本機）有 1M/…/1D；日K是日盤，intraday 含夜盤 | 現價（夜盤收盤 46,140）與日K收盤（日盤 47,242）是不同東西，別混 |
