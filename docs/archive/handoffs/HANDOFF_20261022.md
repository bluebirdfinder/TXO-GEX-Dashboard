## 3. 踩過的坑

| 坑 | 處理 |
|---|---|
| Bash 傳含中文的 curl `-d` 會被 cp950 弄壞 | 先用 Python 寫成 UTF-8 JSON 檔，再 `--data-binary @檔` |
| `curl` 測 8000 可能連 8 秒都沒回 | 8000 卡死時網頁整個開不出來；改走 8001 |
| 8000 重啟：結束 python 後排程會自己重啟，但啟動前要 `git fetch`，可能要 5～6 分鐘 | 先告知使用者，休市時做；驗證 provider |
| `pdftoppm` 沒裝 | 讀 PDF 用 `pymupdf`（`import pymupdf`） |
| Windows 的 `sleep N` 被擋 | 用 Monitor 的 until 迴圈 |
| 工作目錄跑到 `trading room/`、再跑回來 | 指令前用絕對路徑 |
| 憑證 `C:\Capital\*.pfx` | **不要讀**；它是使用者的群益憑證 |
