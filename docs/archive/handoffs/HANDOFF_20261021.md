## 4. 踩過的坑

| 坑 | 處理 |
|---|---|
| 工具的安全檢查偶爾暫時失效（Bash／Edit 回「no verdict」） | 不要連續重試，改用 Read／Grep／Write 等工具，稍後再試 |
| Bash heredoc 會吞掉 `\n`、`\u` | 補丁腳本用 Write 寫成 `.py` 檔再執行；字串內換行用 Edit 工具改 |
| 證交所 openapi 憑證缺 Subject Key Identifier | Python 用 `ssl.create_default_context()` 並關閉 `VERIFY_X509_STRICT` |
| MIS `getChartData1M` 標籤＝K 棒**結束**時間，分鐘可寫 60（`'226000'`＝23:00:00），列沒有日期 | `scripts/mis_session.py` 的 `parse_mis_ticks` 已處理（含跨午夜、重複分鐘）；夜盤另有 04:60 特殊 K 棒（desk 視窗已修覆盤） |
| 專案檔是 CRLF | 用 Python 讀（轉 LF）再以 `newline='\n'` 寫回，git 會顯示最小 diff |
| `git worktree remove` 報 Permission denied（OneDrive） | 資料夾已刪，登記殘留，不影響 |
| 另一個「desk（台選鳥）」視窗也在改 `room.html`／`room.js`／main | push 前一律 `git fetch`、rebase 到最新 origin/main，確認純往前再推 |
| 內建瀏覽器面板有時被隱藏，截圖會逾時 | 改用 `javascript_tool`／`read_page`；要截圖時 `resize_window` 到桌面寬度 |
| 8000 是 runner 的 clone，不是共用資料夾 | 要讓 8000 看到新程式：push 到 main 後殺 8000 的 python（約 1 分鐘無報價，**先告知使用者、休市時做**），排程會重啟並 hard-sync；做完驗證 provider=FUBON |
