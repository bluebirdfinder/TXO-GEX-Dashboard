2. 只能操作 Claude 自己建立的分頁群組：`tabs_context_mcp(createIfEmpty=true)` 開新群組，再導向 `https://revive.rstock.com.tw/main-page`（**不要用首頁 `/`**，圖表不會出來）。
3. 打開後要等約 20～30 秒（「使用者驗證中…」），工具列（1分/5分…／技術指標按鈕）才會完整出現；**太早點工具列座標會點錯地方**（這次曾誤點到商品搜尋框）。確認工具列字樣清楚可讀再開始點。
4. 切商品：點圖表左上角商品名 → 輸入「聯電」（先 Ctrl+A 清掉原文字）→ 選 `CCF-1`。**切換後圖表可能很久不更新**，原因未確認（疑似背景分頁繪圖被節流，也可能與連線上限有關）。
5. **圖表剛載入時中間畫布常是空白的**，要點一下畫布、等幾秒、再點左下角「縮放至全部」（手機圖示那顆）才會畫出 K 棒並跳到最新時間；沒做這步會一直誤判成「資料沒進來」。
6. **新增「大戶散戶動能」子圖（`futures--revive-ti`）極不穩定（2026-10-07 實測約 1/16 成功率）**：點「技術指標」→ 搜尋或捲動找到 `futures--revive-ti`（搜尋關鍵字「大戶」會同時列出 `futures--revive-tdcc`，那個是集保持股比例，不是要的）→ 點一下 → 關閉視窗 → 檢查圖表下方是否多出「大戶散戶動能／大戶比例／同向指標」三個子圖。沒出現就重複點，沒有固定次數保證成功；失敗時完全沒有錯誤訊息。**強烈建議請使用者本人有空時手動加上去後按「儲存」**，讓它變成帳號預設模板，之後排程只要重新整理頁面就會自動帶出來，不必每次賭運氣新增。
7. 只讀、不點：儲存（除非上一點那種使用者本人知情要求的情境）、指標旁的 ✕（刪除）、設定視窗的確認、任何改版面的按鈕。游標勿停在指標圖例旁（會冒出 👁️⚙️✕）。
