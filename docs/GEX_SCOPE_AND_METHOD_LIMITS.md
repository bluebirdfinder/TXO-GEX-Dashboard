# GEX 引擎現行範圍與方法限制(2026-10-09 盤點,未改引擎)

> 來源:與老墨 MOFI 頁面對照(見 [MOFI_GEX_COMPARISON_20261009.md](MOFI_GEX_COMPARISON_20261009.md))+ 本 repo 讀碼。
> 目的:任何人看到 Call Wall / Put Wall / Zero Gamma / 標準 Gamma Flip / 總 GEX 時,知道它的前提。**這些是模型輸出,不是預測。**

## 目前怎麼算(`scripts/fetch_and_calc_vision.py` `calculate_true_gex_profile`)
| 項目 | 現況 |
|---|---|
| 公式 | `OI × Γ × S² × 50 / 1e8`,買權 +、賣權 −(符號、乘數 50 與業界通行寫法一致) |
| 單位 | **未乘 0.01**:數字是「指數每動 1%」標準值的 **100 倍**(例:總 GEX 185.4 ≈ 通行單位 1.85 億/每 1%)。圖軸只寫「億 TWD」 |
| 波動率 | 單一當日官方臺指 VIX(10/8 為 24.55%),所有履約價、所有到期共用;不是每履約價 IV |
| 標的價 S | 加權現貨指數 + Black-Scholes(r=1.5%);通行做法為各到期期貨價 F + Black-76 |
| 到期天數 | 到 13:30 結算時刻的小數天/365,下限 0.5 天 |
| 合約範圍 | 只取 4 檔:最近週三選 w1、次一檔週三選 w2、最近週五選 fri、近月月選 mth。**遠月(次月以後)與更遠週五選未計** |
| 履約價範圍 | 現價附近 ±900 點(約 37 檔) |
| 買/賣權牆 | 買權側 GEX 最大 / 賣權側 |GEX| 最大(兩側分開比);通行寫法另有「淨 GEX 最大/最小」 |
