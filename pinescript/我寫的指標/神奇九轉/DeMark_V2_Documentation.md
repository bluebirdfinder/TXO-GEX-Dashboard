# 📉 神奇九轉 V2 (DeMark Sequential V2) 升級實戰手冊

這份文件記錄了 **神奇九轉 V2** 指標的改版邏輯、與傳統標準 TD Sequential 指標的差異，以及如何使用內建的動能過濾器。這套系統專為「交易直覺」與「實戰運用」量身定做，不僅能尋找逆勢轉折點，還能捕捉順勢發動的第一時間。

---

## 🌟 1. V2 與標準版 (TD Sequential) 的核心差異

### 傳統標準版 (TD Sequential)
* **核心思想**：主要用於「逆勢找轉折（Mean Reversion）」。
* **運作方式**：專注於 Setup (9) 與 Countdown (13)。它會去計算趨勢動能何時「竭盡」，因此你通常只會留意 K 線上末段的數字 `7, 8, 9`（潛在反轉起點）與 `13`（確立反轉）。
* **缺點**：對於一段剛萌芽的「初升段」或「初跌段」發動，前期數字 `1~3` 因為被認為勝率較低、雜訊過多，在實戰中常常遭到忽略或不顯示。

### V2 實戰升級版
* **這不僅是一個找底部的指標，更是「抓突破與發動」的指標。**
* **創新功能**：在保留原有的 `7, 8, 9` 與 `13, R` 竭盡點訊號之上，重新賦予了 `1, 2, 3` 新的戰略意義——**作為「順勢動能發動（初升段/初跌段）」的試單訊號**。
* **雜訊處理**：為了解決 `1~3` 雜訊過多的問題，深度結合了 **MACD** 與 **AO (Awesome Oscillator)** 雙指標進行雙重動態過濾。

## 🎨 2. 視覺邏輯大重構：空間語義化

傳統指標在標記買賣點時，經常因為其原生演算法（例如空頭趨勢下的 Buy Setup），將數字標記在反直覺的位置，容易干擾實戰判斷。V2 徹底打破了這個限制，採用**「行動區絕對分層」**：

### ⬇️ K 棒下方：多頭行動區 (尋找買點)
只要符號出現在 K 棒**下方**，就代表這是你的**做多/買進**機會區間。
* **初升段試多單 (1, 2, 3)**：紫色系 (`#D1C4E9` -> `#4527A0`)
  - 代表價格突破整理區間，剛開始往上拉升。此處為右側交易的順勢追擊點。
* **賣盤竭盡抄底 (7, 8, 9, 13, R)**：黃/橘/粉紅色系 (`#FFEE58` -> `#F48FB1`)
  - 代表原本的跌勢已經力竭，市場可能即將迎來反彈或 V 型反轉。此處為左側交易的逆勢摸底點。

### ⬆️ K 棒上方：空頭行動區 (尋找賣點 / 減碼)
只要符號出現在 K 棒**上方**，就代表這是你的**做空/減碼**機會區間。
* **初跌段試空單 (1, 2, 3)**：藍色系 (`#B3E5FC` -> `#0288D1`)
  - 代表價格跌破支撐，剛開始往下跌。此處為右側交易的順勢放空，或為多單最後逃命點。
* **買盤竭盡減碼 (7, 8, 9, 13, R)**：綠色/青綠色系 (`#A5D6A7` -> `#4DD0E1`)
  - 代表原本的漲勢過熱、買盤竭盡，市場可能即將迎來回檔或 A 型反轉。此處為左側交易的逆勢放空、或是多單逢高獲利了結點。

## 🛡️ 3. 專屬過濾器機制 (Filter for 1~3)

為了讓 `1, 2, 3` 成為具有高期望值的實戰進場點，V2 獨立內建了「雙動能過濾系統」，只在動能確定與趨勢同向時，才允許亮燈。

### 過濾器元件
1. **MACD (12, 26, 9)**：判斷短期與中期資金流向（取金叉/死叉）。
2. **AO 動量震盪指標 (Awesome Oscillator, 5, 34)**：利用中長期均線動能確認大趨勢方向（取零軸之上/之下）。

### 過濾邏輯 (以預設的「MACD 金/死叉 + AO 零軸之上/下」為例)
* **當初升段 (多頭) 1~3 觸發時**：
  - 系統不僅檢查價格是否創高，會同步嚴格檢查「MACD 是否處於金叉多頭狀態」且「AO 同時大於 0」。兩者皆成立，紫色的 1~3 才會顯示於K棒下方。
* **當初跌段 (空頭) 1~3 觸發時**：
  - 系統檢查「MACD 是否處於死叉空頭狀態」且「AO 同時小於 0」。兩者皆成立，藍色的 1~3 才會顯示於K棒上方。

> [!TIP]
> **為什麼這樣過濾？**
> 任何在箱型盤整期的震盪，都會產生無數次無效的 `1, 2, 3`。有了雙過濾器後，V2 可以完美將盤整期間的雜訊屏蔽，只在「價格帶起 MACD，且被 AO 中長天期均線認可」的**強勢爆發點**才提醒你進場。

## ⚙️ 4. 設定面板操作指南

V2 的 TradingView 設定面板已完全中文化與邏輯化：

1. **🎨 Display 顯示設定**：指標全局開關。
2. **⬇️ K棒下方顯示 / ⬆️ K棒上方顯示**：自由調整試單(1~3)與竭盡(7~13)的視覺顏色。如果你看膩了內建的配色，可以直接透過調色盤設定。
3. **📏 TDST 線條顏色**：自訂 Setup 9 完成後產生的 TDST 支撐/壓力線顏色與線型 (實線/虛線/點線)。
4. **🔍 初升段過濾器 (Filter for 1~3)**：若你想觀察不同過濾強度的表現，可以在此切換：
   - `無過濾 (顯示所有1~3)`：適合進階老手自行搭配肉眼判斷圖表。
   - `MACD 金/死叉`：僅做短期動能過濾。
   - `AO 零軸之上/下`：僅做中期趨勢確認。
   - `MACD 金/死叉 + AO 零軸之上/下`：預設模式，過濾強度最高，只抓絕對重疊的發動點。

## 🚀 5. 給使用者的心法與 V3 未來展望

V2 的核心理念是：**用 `1, 2, 3` 抓魚頭，用 `7, 8, 9` 找魚尾。**
在使用時，建議搭配基本面與長線趨勢看待。

**未來展望 (V3 Blueprint)：**
目前如果遇到極端劇烈洗盤的飆股，動能指標 (MACD/AO) 依然有可能產生延遲或被騙線。為此，未來的 V3 版本計畫導入 **「成交量 (Volume) 過濾系統」** 及 **「均線 (MA) 斜率系統」**，讓指標不只判斷價格的動能，還能藉由「主力真金白銀的成交量」來終極確認初升段的真偽。
