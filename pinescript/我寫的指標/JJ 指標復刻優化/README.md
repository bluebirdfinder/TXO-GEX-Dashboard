# JJ 指標系列 (JJ Indicators) - 復刻與優化專案

## 📌 專案概述
本專案旨在復刻並優化 JJ 老師的核心交易指標系統。JJ 指標以視覺化、直覺化的動能追蹤為核心，透過獨特的「鬼爪」設計與雙層 MACD 邏輯，幫助交易者精準捕捉起漲點並規避主跌段。

**目前版本**：**V4.1（當前最新版）** | V4.0（穩定舊版）| V3（歷史版）

本系統由三個互相協作的指標組成：
1. **J Indicator Advanced - Ghost Claws (鬼爪)**：主圖指標，整合布林通道、四條核心均線、四分法量化濾網（ADX/BB/乖離率/MFI）、8 個訊號圖示、16 種商品智能辨識、Telegram 即時通知。
2. **J Indicator Advanced - Super MACD**：副圖指標，採用「雙層 MACD」邏輯，比傳統 MACD 更快反應動能轉折。
3. **J Indicator Advanced - Super CCI**：副圖指標，針對超買超賣區進行精確標註，並內建 MACD 過濾器防鈍化。

## 🛠️ 三大核心指標說明

### 1. 鬼爪指標 (Ghost Claws) — 最新穩定版：V3 / 開發中：V4
*   **設計理念**：利用 SMA17 的斜率擴張（Spread）模擬獵食者的爪子張開。趨勢強時收斂，跌勢來時張開。
*   **V4 完整訊號系統（8 個，遠低於 TradingView 64 plotchar 上限）**：

| 圖示 | 訊號 | 信心度 | 對應操作 |
|:---|:---|:---|:---|
| 🐣 | **一般藍鳥** | 低（試探）| MACD 翻正，小量試單 |
| 🐦 | **強力藍鳥** | 中高（超跌）| 負乖離過大，積極試單 |
| ✈️ | **弱火箭** | 中（量能不足）| 方向對但未帶量，輕倉觀察 |
| 🚀 | **強火箭** | 高（量價齊揚）| MFI 帶量突破，正式建倉 |
| ⚡ | **動能再啟** | 中（波段延續）| 整理結束，可補回前波減碼部位 |
| 🛸 | **強力動能再啟** | 高（MA7 確認）| MA7 支撐彈升，積極補倉 |
| 💰 | **錢袋** | — | 減碼落袋（1/3 至 1/2）|
| ⚠️ | **警告** | — | 全數清倉 |

*   **V4 智能三段出場**：ADX 弱快出（單條件）/ 一般雙確認 / 強噴三重確認（MA17 為最後防線）
*   **V4 MA7 強度分級**：S（沿MA7強噴）/ A（沿MA17強勢）/ B（一般多頭）/ C（空頭），面板即時顯示

### 2. 超級 MACD (Super MACD)
*   **核心技術**：**雙層 MACD 判色機制**。副 MACD (3/15/5) 控色，主 MACD (12/26/9) 控高度。
*   **優勢**：能在主 MACD 還在零軸以下（水下）時提早亮起紅色，捕捉先機（「水下翻紅」效應）。

### 3. 超級 CCI (Super CCI)
*   **核心技術**：**關鍵水位標註 + MACD 動能過濾器**。
*   **優勢**：在強勢趨勢中，CCI 容易「鈍化」停在超買區。加入 MACD 斜率過濾後，有效減少誤判。

## 🚀 安裝與使用指南
1. 打開 TradingView 的 Pine Editor。
2. 建立三個新腳本，將對應的 `.pine` 程式碼（V3 或 V4）分別貼入並儲存。
3. 將三個指標加入圖表。
4. **推薦配置**：主圖 `Ghost Claws` + 副圖1 `Super MACD` + 副圖2 `Super CCI`
5. **Telegram 通知設定**：快訊 → Webhook URL 填入 GAS 位址（詳見 `Telegram_Credentials.md`）。

## 📈 最佳實踐 (Best Practices)
*   **多空鐵律**：所有買入訊號必須建立在「持股線 (MA17) > 多空線 (MA88)」的大前提下。
*   **強度分級操作**：Grade S 的股票（面板顯示 S 強噴）抱到 MA7 失守才減碼；Grade A/B 用標準訊號操作。
*   **動能再啟的意義**：⚡/🛸 代表「前波整理結束，下一段啟動」，適合補回前波錢袋已賣出的部位。
*   **共振操作**：副圖 Super MACD 提早翻紅，且主圖同時出現 🐦 或 ⚡ 訊號，為高信心度進場點。
*   **安全防守**：出現 ⚠️ 訊號，或在 Grade S 時價格首次跌破 MA7，應考慮減碼防守。
