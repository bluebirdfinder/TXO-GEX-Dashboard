## 🦅 鬼爪 (Ghost Claws) 核心演算法：SMA17 斜率法

鬼爪的核心在於「視覺化趨勢的張力」。我們在 V2 版本中選用了 **SMA17 斜率法**，這是經過多次測試後最能還原 JJ 原版視覺感受的方案。

### 1. 核心算式
```pine
// 計算 SMA17 的斜率擴張
// claw_lookback 預設為 2，代表觀測 2 根 K 棒前的 MA 位移
spread = math.max(0, ma17[claw_lookback] - ma17)

// 根據張力倍數繪製爪子
claw_upper  = ma17 + spread * claw_mult_2 // 外層 (螢綠)
claw_middle = ma17 + spread * claw_mult_1 // 中繼 (深黃)
```

### 2. 邏輯解析
- **當價格強勢上攻**：MA17 會快速上升，`ma17[2] - ma17` 為負值，`math.max(0, ...)` 取 0，此時爪子會完全收攏在 MA17 上。這代表「趨勢強勁，無需警覺」。
- **當價格開始盤整或緩跌**：MA17 升勢放緩或轉向，`spread` 數值變大，爪子會從 MA17 上方「彈開」。這在視覺上營造出一種「防守區域」或「重力場」的感覺。

## 📊 Super MACD 核心技術：雙層同步機制

Super MACD 解決了傳統 MACD 的「滯後性」與「水下無感」問題。

### 1. 雙層架構
| 層級 | 參數 | 職責 |
| :--- | :--- | :--- |
| **主 MACD (Height)** | 12 / 26 / 9 | 決定柱狀體的物理高度（標準強度） |
| **副 MACD (Color)** | 3 / 15 / 5 | 決定柱狀體的顏色（動能反應速度） |

### 2. 判色邏輯
- **水下翻紅 (JJ 獨門假設)**：當副 MACD 的快線穿越慢線時，即使主 MACD 仍在零軸下方，柱體也會直接變為**紅色**。這代表動能已在底層悄悄翻轉，是極佳的左側交易訊號。

## 🏹 Super CCI 核心技術：防鈍化過濾器

CCI 在單邊趨勢中極易出現「鈍化」（持續停留在超買/超賣區）。我們透過 **MACD 動能同步檢查** 來解決此問題。

### 1. 過濾機制
- **開啟過濾器後**：
    - 只有當 `CCI > 100` **且** `MACD Hist > Hist[1]` (動能轉強) 時，才會亮起賣點。
    - 這確保了你不會在一段大趨勢的剛開始就因為 CCI 過熱而過早離場。

## 🔄 V3 綜合訊號矩陣 (Signal Matrix)

V3 採用六階層圖示系統，不再依賴顏色深淺，確保行動裝置判讀清晰。

| 訊號圖示 | 觸發條件 (整合版) | 交易行為 |
| :--- | :--- | :--- |
| 🐣 **一般藍鳥** | MACD 翻正 + MA17 > MA88 + 站上布林中軌 | **左側試單**：等待進一步確認。 |
| 🐦 **強力藍鳥** | 同上 + 負乖離達到超跌門檻 | **積極試單**：超跌反彈共振，勝率高。 |
| ✈️ **弱火箭** | MA17 穿越 MA88 + MACD > 0 + MFI 量能不足 | **右側輕倉**：主結構轉多，但欠缺買盤動能。 |
| 🚀 **強火箭** | 同上 + MFI 大於強勢門檻 (帶量) | **波段加碼**：量價齊揚，建立主要波段部位。 |
| 💰 **錢袋** | MACD 連續衰退 2 次 (若 ADX>25 則放寬至 3 次) | **階段獲利**：建議減碼 1/3 或 1/2。 |
| ⚠️ **警告** | MACD 死叉 + 跌破布林中軌 | **全數清倉**：趨勢轉折，落袋為安。 |

## 🛠️ 參數優化建議

## 🧠 V3 量化核心：智能路由與四分法濾網

V3 版本補齊了 JJ 系統在盤整期與極端行情的盲點，完整落實了最新的「趨勢、擺盪、動能、量能」四大維度框架 (四分法)。

### 1. 智能商品辨識 (AI Router)
- **邏輯**：利用 `syminfo.root` 自動辨識 16 種商品分類（涵蓋台股、期貨、加密貨幣、外匯、原物料等）。
- **目的**：免除使用者手動調整參數的痛苦。例如加密貨幣需要 ±20% 的乖離率才算超跌，而美股指數僅需 ±3%。

### 2. 多重濾網驗證 (Multiple Filters)
- **乖離率 (Bias)**：測量價格偏離 MA88 的幅度，用以區分「一般藍鳥」與「強力藍鳥」。
- **資金流量 (MFI)**：取代傳統 OBV，捕捉成交量中的真實買盤動能。用以區分「無量飛機」與「帶量火箭」。
    - **MFI 帶量驗證**：✈️（MFI 未達門檻）vs 🚀（MFI 超過強勢門檻）提升準確度。
    - **ADX 盤整過濾**：ADX 低於商品基準值時，訊號自動半透明化，提醒交易者降低出手頻率。

## 🏆 V4 核心架構：三段式自適應出場系統

### 1. 智能三段出場矩陣

V4 利用 `auto_adx`（AI Router 為每種商品設定的基準值）自動推算出三個出場等級，無需手動調整：

```pine
float adx_strong = final_adx_thresh + 10.0  // 強噴基準 = 一般基準 + 10

// 弱勢/盤整（ADX < auto_adx）：單條件快出
exit_cond := ta.crossunder(hist, 0)

// 一般趨勢（auto_adx ≤ ADX < auto_adx+10）：雙重確認（V3 標準）
exit_cond := (hist < 0) and (close < bb_basis)

// 強噴趨勢（ADX ≥ auto_adx+10）：三重確認，持股線是最後防線
exit_cond := (hist < 0) and (close < bb_basis) and (close < ma17)
```

| ADX 等級 | 範圍 | 警告條件 | 錢袋次數 |
|:---|:---|:---|:---:|
| 弱勢 | < auto_adx | MACD 死叉（單條件）| 2 |
| 一般 | auto_adx ~ auto_adx+10 | + 跌破 BB 中軌 | 2 |
| 強噴 | ≥ auto_adx+10 | + 跌破 MA17 | 3 |

### 2. MA7 強度分級（Trend Strength Grade）

基於 MA7（白線）的貼線程度，將趨勢強度分為四級：

| 等級 | 判定條件 | 錢袋特殊觸發 | 面板顏色 | Pine Script 色碼 |
|:---|:---|:---|:---|:---|
| **S 強噴** | ADX ≥ auto_adx+10 AND close > MA7 | 3次MACD衰退 **或** 首次跌破MA7（兩者皆觸發）| 🟡 **金黃** | `color.new(#FFD700, 0)` |
| **A 強勢** | auto_adx ≤ ADX < auto_adx+10 | 標準 2 次 MACD 衰退 | 🔴 **紅色** | `color.red` |
| **B 一般** | ADX < auto_adx，且多頭排列 | 標準 2 次 MACD 衰退 | 🔵 **藍色** | `color.new(#4488FF, 0)` |
| **C 空頭** | MA17 < MA88 | 不適用（不做多）| 🟢 **綠色** | `color.lime` |

> **顏色設計哲學**：S級金黃（仙水黃金聖鬥氣風格）在黑底下最展眼；A級紅色代表積極進攻；B級藍色穩健中性；C級綠色是警示，提醒不宜做多。

> **設計哲學**：Grade S 有**兩種**減碼觸發方式，增加靈活性。首次跌破 MA7 是「強勢股預警信號」，比等 MACD 衰退提前半拍。

### 3. ⚡🛸 動能再啟訊號（Momentum Restart）

**設計背景**：V3 在強勢股高檔整理後無法觸發新訊號（MACD 未轉負，MA17 未重新穿越 MA88），導致下一段漲幅的起始點「斷訊」。

**觸發邏輯**：
```pine
// 前提：MACD 曾連續收縮（2根以上）
bool macd_was_cooling = (hist[1] < hist[2]) and (hist[2] < hist[3])

// 現在：MACD 首次回升，且仍在正區間
bool macd_now_turning = (hist > hist[1]) and (hist > 0)

// 基礎再啟（is_holding 中才觸發，代表「補回前波減碼」）
bool cond_restart = macd_was_cooling and macd_now_turning
                    and is_bull_trend and (adx_val > final_adx_thresh) and is_holding

// ⚡ 普通再啟：基礎條件成立
// 🛸 強力再啟：同上 + 昨天曾貼近MA7（low ≤ ma7*1.01），今天收盤站回MA7上方
bool ma7_bounce = (low[1] <= ma7[1] * 1.01) and (close > ma7)
```

**狀態機行為**：⚡/🛸 觸發後 `reduce_count` 歸零，可無限次觸發（SNDK 三段噴出的設計基礎）。

**完整訊號高度軸（8 個訊號，遠低於 TradingView 64 上限）**：
```
🐣 地面起步 → 🐦 積極起步 → ✈️ 低空 → 🚀 近地軌道 → ⚡ 大氣層外 → 🛸 星際
                                                                     💰 收割  →  ⚠️ 出清
```
