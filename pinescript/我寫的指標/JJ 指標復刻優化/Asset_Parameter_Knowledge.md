# 商品參數知識庫 (Asset Parameter Knowledge Base)
> **用途**：跨指標通用。每次開發新指標時，直接引用此文件的分類與參數，無需重新討論。
> **最後更新**：2026-05-13（JJ 鬼爪 V4.1 整合版）

---

## 核心參數說明

| 參數 | 說明 | 值越大代表 |
|------|------|-----------|
| `bias_pos / bias_neg` | MA88 乖離率門檻 (%) | 需要更大的超漲/超跌才觸發強力訊號 |
| `mfi_thresh` | MFI 量能門檻 | 需要更強的量能才確認強勢 |
| `adx_thresh` | ADX 盤整門檻 | 需要更強的趨勢才解除淡化 |

**參數設計原則：**
- 波動率越高 → `bias` 越大（避免頻繁觸發追高/超跌）
- 趨勢性越強 → `adx` 越高（確保訊號在真趨勢中出現）
- 流動性越低 → `mfi` 適度放寬（量能較薄，MFI 容易失真）

### 4.3 農產品

#### 商品特性總覽

**🌽 穀物類（流動性佳，走勢最穩定，最適合 MA 系統）**
- **黃豆 `ZS`**：農產品中流動性最佳，機構與基金大量參與，走勢趨勢性強，假突破少。主要受美國出口需求、拉尼娜/聖嬰氣候、巴西/阿根廷產季影響。bias 7% 足夠。
- **豆油 `ZL`**：與黃豆壓榨高度連動（Crush Spread），走勢幾乎同步。流動性略低於黃豆，相同 bias。
- **玉米 `ZC`**：全球生產量最大的糧食期貨，流動性僅次於黃豆。走勢相對穩定，乾旱季節為主要驅動。bias 6%，略嚴於黃豆。

**🌿 軟性商品（季節性主導，高波動）**
- **棉花 `CT`**：有明確的種植（3~5月）與收穫（9~11月）季節性週期。波動率高，流動性中等，乖離 10%。

## 五、外匯期貨

#### 外匯市場特性
外匯是所有資產類別中**波動率最低、趨勢最穩定**的市場之一。以下是理解外匯期貨的關鍵：

- **24小時連續交易**：外匯沒有真正的開盤/收盤，日線 K 棒的 open/close 意義較弱
- **均值回歸vs趨勢**：主要貨幣對（EUR/USD、GBP/USD）有明顯的均值回歸特性，乖離率門檻應最嚴格（3%）
- **央行風險**：特別是日圓，日本央行的干預可能在數分鐘內造成 3%+ 的逆轉，需要更寬鬆的 bias
- **商品貨幣**：澳幣（AUD）跟隨鐵礦石/銅價，加幣（CAD）跟隨原油，可交叉參考商品走勢確認訊號
- **MFI 失真**：外匯的成交量資料不完整（OTC 市場），MFI 僅供參考，建議調高門檻至 55

## 六、股票指數特性補充

#### 各地區指數的本質差異

**🇺🇸 美股指數**
- **S&P 500 / ES**：由 500 家大型股組成，高度多元化，長期向上偏移（均值回歸較弱）。乖離 3% 就已是相當大的偏離。MA 系統在日線/週線效果最佳。
- **那斯達克100 / NQ**：科技股比重 >40%（AAPL, MSFT, NVDA, AMZN, META），波動比 S&P 大 1.5 倍，利率敏感性最強。升息期間訊號可靠性下降。
- **羅素 2000 / RTY**：美國中小型股，流動性低於大型股指數，走勢更接近個股，假突破較多，乖離 5%。
- **道瓊 / YM**：僅 30 檔傳產藍籌股，指數編製方式為「價格加權」（不是市值加權），波動性在三大指數中最低。

**🇯🇵 日本指數**
- **日經 225 / NKD**：日圓匯率影響極大（日圓貶值 → 出口股上漲 → 日經上漲）。分析日經前必須先看日圓走勢。2024年創歷史新高後波動率大幅上升。

**🇭🇰 香港指數**
- **恆生 / HSI**：受中國政策、地產危機、外資流出影響，波動極大。近年跌幅超過 50%，均值回歸假訊號多，乖離 8% 是最低要求。
- **國企指數 / HHI**：比恆生更直接反映中國大陸經濟，政策風險更高，波動性略大於 HSI。

**🇩🇪 歐洲指數**
- **DAX / FDAX**：德國工業導向，能源危機（2022烏俄）衝擊明顯，但復甦彈性也強。歐洲時段流動性最佳（台灣深夜 15:00~23:00 UTC）。

## 七、貴金屬與能源特性補充

#### 貴金屬市場本質
- **黃金的避險屬性**：危機時「Flight to Quality」資金湧入，美元走強時通常承壓。但近年（2024後）出現「強美元 + 強黃金」的罕見共存現象，傳統相關性正在瓦解。
- **白銀的雙重屬性**：50% 工業需求（太陽能電池板、電子）+ 50% 貴金屬。漲得比黃金慢，但一旦啟動，漲幅通常是黃金的 2~3 倍（稱為 Gold/Silver Ratio 收斂行情）。
- **鈀金的獨特性**：主要用於汽車催化轉換器（燃油車），全球 80%+ 產自俄羅斯/南非。供應集中度極高，地緣衝擊可導致短期暴漲暴跌，不建議用固定參數操作。

#### 能源市場本質
- **原油的兩面性**：原油有明確的趨勢性（可使用 MA 系統），但受 OPEC+ 減產決定影響。每次 OPEC 會議都可能造成 5~10% 的跳空，這種「非技術性跳空」是 MA 系統的最大敵人。
- **天然氣的極端特性**：天然氣是所有主流期貨中，**單位時間波動率最高的商品**。它受季節性（冬季用暖氣、夏季用冷氣）、庫存週報（每週四美國 EIA 報告）、極端天氣（颶風影響灣區生產）三重因素疊加影響。建議：
  - 只看日線/週線的大趨勢，4H 以下訊號可靠性極低
  - bias 12% 是最低要求，某些時期需要手動調整至 15~20%
  - 天然氣的「均值回歸性」很強，長期均值約 2~4 美元，超漲超跌最終都會回來

## 八、加密貨幣特性補充

#### 加密市場的獨特規則

**市場結構**
- **24/7 無休交易**：沒有隔夜跳空的概念，但每日 00:00 UTC（台灣早上 8:00）有輕微的週期性流動性低點
- **市值高度集中**：比特幣（BTC）市占率通常 50~60%，以太幣（ETH）15~20%，其餘 Altcoins 共享剩餘。BTC 走勢決定整個市場方向。
- **無漲跌幅限制**：單日波動 20%+ 並不罕見，bias 20% 是最低標準

**週期性規律**
- **比特幣減半週期（約每4年）**：減半後 12~18 個月通常是大牛市，之後進入熊市週期。這個大週期比任何技術指標都重要。
- **山寨季（Altcoin Season）**：BTC 進入高位橫盤後，資金通常流向 ETH，然後擴散至主流 Altcoin，最後才到小型幣。

**技術分析的適用性**
- **MA 系統有效性**：加密市場的趨勢性非常強，MA 系統在牛市期間效果極好。但熊市中假突破極多，建議配合週線確認方向。
- **MFI 失真**：各交易所的成交量數據不一致，MFI 建議調低門檻（48~50），以免錯過真實的量能啟動。
- **推薦參數組合**：bias 20%, MFI 48, ADX 18；鬼爪張力倍數建議調高至 1.0/1.8（預設 0.6/1.2）

| 商品 | 特性 | 參數建議 |
|------|------|----------|
| BTC (比特幣) | 市場領導者，MA 系統最有效 | bias 20%, 鬼爪張力可略調低 |
| ETH (以太坊) | 跟隨 BTC，波動略大 | 與 BTC 相同 |
| SOL, BNB 等主流幣 | 與 BTC 高度相關，彈性更大 | bias 20~25% |
| 小型 Altcoins | 流動性差，操控嚴重 | 不建議使用自動化訊號 |

## Pine Script 辨識技巧

```pine
// 辨識 ADR（美國存託憑證）：NOK, ARM, BABA, TSM 等
syminfo.type == "dr"

// 辨識台股 ETF 字尾
str.endswith(syminfo.ticker, "L")  // 正2
str.endswith(syminfo.ticker, "R")  // 反1
str.endswith(syminfo.ticker, "B")  // 債券
str.endswith(syminfo.ticker, "A")  // 主動型
str.endswith(syminfo.ticker, "U")  // 期貨/商品型

// 台股個股期貨萬用捕捉（指數期貨已在前方被攔截）
syminfo.country == "TW" and syminfo.type == "futures"

// 美股判斷
syminfo.country == "US" and (syminfo.type == "stock" or syminfo.type == "fund" or syminfo.type == "dr")
```
