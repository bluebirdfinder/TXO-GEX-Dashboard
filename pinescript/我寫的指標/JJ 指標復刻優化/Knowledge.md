## 1. 乖離率 (Bias)
*   **🎓 專業定義**：
    乖離率是指當日收盤價與移動平均線（MA）之間的差距百分比。計算公式為：`[(當日收盤價 - 移動平均線) / 移動平均線] * 100%`。它反映了股價偏離平均成本的程度。
*   **💡 白話解釋 (橡皮筋理論)**：
    均線是「家」或「主人」，股價是出門亂跑的「哈士奇」。當橡皮筋拉得太緊（乖離率過大），不論是衝太快（正乖離）還是跌太深（負乖離），哈士奇最終都會被拉回主人身邊。
*   **🎯 實戰運用 (JJ 鬼爪優化)**：
    - **負乖離過大**：當「藍鳥 🐦」出現且負乖離率極高時，代表超跌後的「報復性反彈」機率極大，是高品質的抄底訊號。
    - **正乖離過大**：當股價創高但遠離 MA17/MA88 時，應警戒隨時可能發生的「回馬槍」修整。

## 2. 量能指標 (Volume Force / OBV)
*   **🎓 專業定義**：
    OBV (On-Balance Volume) 稱為能量潮，透過將上漲日的成交量累加、下跌日的成交量扣除，來觀察資金的流向。Volume Force 則是更細緻地計算成交量對股價推動的力道。
*   **💡 白話解釋 (體力計)**：
    股價漲跌是「跑步跑了多遠」，成交量則是「跑步消耗的體力」。
*   **🎯 實戰運用 (JJ 鬼爪優化)**：
    - **推動力驗證**：如果「火箭 🚀」發射但體力計沒動，代表這是一場「虛弱的奔跑」，高機率是假突破，應避免大額加碼。

## 3. 量價背離 (Divergence)
*   **🎓 專業定義**：
    當股價走勢創出新高（或新低），但相對應的技術指標或量能指標卻未同步創出新高（或新低），即稱為背離。這通常是趨勢動能衰竭、即將反轉的預警。
*   **💡 白話解釋 (說謊偵測器)**：
    一個人在吹牛說他很有力氣（股價創高），但實際上他流的汗越來越少、心跳越來越慢（成交量萎縮）。這代表他在說謊，這股漲勢只是表面上的硬撐。
*   **🎯 實戰運用 (JJ 鬼爪優化)**：
    - **優化「錢袋 💰」**：當出現量價背離時，代表買盤力竭，這時「錢袋」訊號應優先噴出，提醒投資者主動防守。

## 4. ADX (平均趨勢指數)
*   **🎓 專業定義**：
    ADX 是一種衡量趨勢「強弱」而非「方向」的指標，數值介於 0 到 100 之間。通常 ADX > 25 代表趨勢強勁，ADX < 20 代表市場進入盤整。
*   **💡 白話解釋 (風速計)**：
    ADX 不看你是往南走還是往北走，它只看現在「風大不大」。
*   **🎯 實戰運用 (JJ 鬼爪優化)**：
    - **雜訊過濾**：在「無風日」（ADX < 20）時，哈士奇（股價）通常只是在門口繞圈圈。此時出現的藍鳥或警告訊號往往是假雜訊，程式應適度降低訊號頻率以減少「被雙巴」的風險。

## 7. 多時框乖離率共振 (MTF Bias Resonance)
*   **🎓 專業定義 (4394ming 心法)**：
    同時觀察日K、週K、月K 三個時框的乖離率方向與極值。當三個時框的乖離率同時出現極端值且方向一致時，反轉力道最強。
*   **💡 白話解釋 (三個時鐘同時報警)**：
    一個鬧鐘響你可能沒注意，三個鬧鐘同時響，你絕對跳起來。多時框乖離率就像三個設定在不同時間軸的鬧鐘，同時亮紅燈才是最高等級的警報。
*   **🎯 實戰運用**：
    - 這是 4394ming 花了 9 年才掌握的技巧，難以用一個程式完全還原。
    - 簡化版：在 JJ 鬼爪中，用「MA88 乖離率（中期）」與「MA200 乖離率（長期）」做雙層過濾已能捕捉大部分共振訊號。

## 11. MFI（資金流量指數）vs OBV（能量潮）比較

*   **🎓 OBV 定義**：漲的交易日累加成交量，跌的日子扣除。產生一條無上下界的累計曲線。
*   **🎓 MFI 定義**：「有量版的 RSI」。將成交量乘以收盤在高低點間的相對位置，計算出 0~100 的振盪器。
*   **💡 白話**：OBV 只看量大量小；MFI 還看「這些量是在 K 棒哪個位置成交的」（上半部 = 買方積極，下半部 = 賣方積極）。

| 比較項目 | OBV | MFI |
|:---|:---|:---|
| 數值範圍 | 無界（難設門檻）| 0~100（易設門檻）|
| 考慮 K 棒內部位置 | ❌ | ✅ |
| Pine Script 函數 | `ta.obv` | `ta.mfi(source, length)` |
| 適合「帶量驗證」 | 🟡 | ✅ 更精確 |

*   **🎯 JJ 鬼爪 V3 決策**：**方案 C 採用 MFI，不採用 OBV**
    - `MFI > 55`：買盤主導，火箭訊號強度提升 → `🚀 強火箭`
    - `MFI < 55`：量能不足，降級 → `✈️ 弱火箭`

*   **💡 白話解釋（隧道理論）**：想像股價走在一條隧道裡，EMA144 是隧道頂，EMA169 是隧道底。股價在隧道內 = 盤整；突破隧道上方 = 強多頭確認；跌破隧道下方 = 強空頭確認。
*   **🎯 與 JJ 鬼爪的關係**：

    - **未來選項**：提供使用者選擇是否顯示 EMA144/EMA169，作為 MA200 的「進階替代版」，不在預設開啟。

## 14. V4 核心設計：智能三段出場矩陣（2026-05-12 Claude 設計）

### 設計哲學
> **趨勢越強，給越多容忍空間；趨勢越弱，越快跑。**

利用 `auto_adx`（AI Router 已為各商品設定的基準）直接推算三個等級，無需新增參數：

| ADX 強度 | 出場等級 | ⚠️ 警告條件 | 錢袋 (減碼) 次數 |
|:---|:---|:---|:---:|
| ADX < `auto_adx` | 弱勢/盤整 | **MACD 死叉（單條件）** 快出保本 | 2 次 |
| `auto_adx` ≤ ADX < `auto_adx+10` | 一般趨勢 | MACD 死叉 + 跌破 BB 中軌（V3 標準）| 2 次 |
| ADX ≥ `auto_adx+10` | 強噴趨勢 | MACD 死叉 + 跌破 BB 中軌 + 跌破 MA17 | 3 次 |

**各商品自動適配範例：**
- 台股個股 auto_adx=20 → 弱(<20) / 一般(20-30) / 強(≥30)
- 加密貨幣 auto_adx=18 → 弱(<18) / 一般(18-28) / 強(≥28)
- 台指期貨 auto_adx=22 → 弱(<22) / 一般(22-32) / 強(≥32)

### 為什麼 MA17 是 Grade S 的最後防線？
這完全符合 JJ 老師「持股線就是防守線」的哲學：
- 強噴股（SNDK、鈦昇類）沿 MA17 或 MA7 走
- MACD 可能短暫死叉或BB中軌被觸碰，但只要MA17 守住 = 多方格局未破壞
- 三重條件同時成立時，才代表真正的趨勢逆轉

## 15. V4 核心設計：MA7 強度分級（2026-05-12 Claude 設計）

強勢股有不同的「貼線方式」：
- **S 強噴**：沿 MA7（白線）走，每次回踩都在 MA7 以上，機構不斷補貨
- **A 強勢**：偶爾跌破 MA7，但守住 MA17（黃線）
- **B 一般**：在 MA17 附近震盪，是標準多頭格局
- **C 空頭**：MA17 < MA88，多空排列轉空

| 等級 | 條件 | 面板顏色 | Pine Script 色碼 | 錢袋觸發方式 | 出場條件 |

## 16. V4 核心設計：⚡🛸 動能再啟訊號（2026-05-12 Claude 設計）

### 設計背景（解決 V3 的架構盲點）

**V3 的盲點：**
- `cond_bird` 需要 `ta.crossover(hist, 0)` → MACD 若整理但未轉負，不再觸發
- `cond_rocket` 需要 `ta.crossover(ma17, ma88)` → MA17 已在 MA88 上方後不再觸發
- 結果：強勢股高檔整理後「再出發」的下一段漲幅，訊號系統無法發出新訊號

### 觸發邏輯
```pine
// 過去 MACD 曾收縮 (2根以上)
bool macd_was_cooling = (hist[1] < hist[2]) and (hist[2] < hist[3])

// MACD 現在首次回升，且仍在正區間
bool macd_now_turning = (hist > hist[1]) and (hist > 0)

// 基礎再啟條件
bool cond_restart_base = macd_was_cooling and macd_now_turning
                         and is_bull_trend
                         and (adx_val > final_adx_thresh)
                         and is_holding        // 已持倉（加碼/補回，非新開倉）
                         and not cond_bird     // 避免與藍鳥重複
                         and not cond_rocket   // 避免與火箭重複

// 強力版：貼近MA7後彈回（高信心度）
bool ma7_bounce = (low[1] <= ma7[1] * 1.01) and (close > ma7)
is_restart_strong = cond_restart_base and ma7_bounce   // 🛸 強力再啟
is_restart_normal = cond_restart_base and not ma7_bounce // ⚡ 普通再啟
```

### 圖示設計邏輯（完整訊號高度軸）
| 訊號 | 象徵 | 所在高度 |
|:---|:---|:---|
| 🐣🐦 一般/強力藍鳥 | 鳥，起步 | 地面 |
| ✈️ 弱火箭 | 飛機 | 低空 |
| 🚀 強火箭 | 火箭 | 近地軌道 |

### 狀態機行為
- ⚡/🛸 觸發後：`reduce_count` 重置為 0，開啟新的計數週期
- 沒有次數上限，強勢股可以連續觸發（例如 SNDK 的三波段噴出）
- `just_reduced_in_wave` **不需要**作為 ⚡ 的阻擋條件（MACD擴張與MACD收縮天然互斥）

## 17. Telegram 商品名稱顯示設計（2026-05-12 決策）

### Pine Script 取得商品名稱的方式
- `syminfo.ticker` → 代碼（2330、SNDK、TXF1!）
- `syminfo.description` → 全名（**台股自動回傳中文**，如「台積電」；美股回傳英文全名）
- 原因：TradingView TWSE/TPEx 資料源使用中文作為主語言欄位

### 建議格式
```pine
string market_tag = syminfo.country == "TW" ? " 🇹🇼" :
                    syminfo.country == "US" ? " 🇺🇸" : ""
string symbol_str = syminfo.ticker + " " + syminfo.description + market_tag
```

**效果：**
- `2330 台積電 🇹🇼`
- `SNDK Sandisk Corp 🇺🇸`
- `TXF1! 台灣加權指數期貨`
- `BTCUSD Bitcoin`

> [!NOTE]
> 在 Gemini 開始寫 V4 程式碼前，建議先在 Pine Editor 貼一行 `label.new(bar_index, high, syminfo.description)` 在任何一檔台股確認實際回傳的字串格式。
