## 一、先認識畫面上有哪些線

打開股票圖表，你會看到幾條彩色的線貼著 K 棒跑，每條線代表不同意思：

| 線的顏色 | 名稱 | 簡單說就是... |
| :--- | :--- | :--- |
| 🟡 **螢光黃粗線** | **持股線 (MA17)** | 最近 17 天的平均股價，代表「短期主力成本」。股價在它上面 = 短期偏多。 |
| 🔴 **桃紅粗線** | **多空線 (MA88)** | 最近 88 天的平均股價，代表「中期多空分界」。持股線在它上面 = 整體趨勢向多。 |
| 🟣 **紫色線** | **年線 (MA200)** | 最近 200 天均價，代表長期趨勢。 |
| ⬜ **白色細線** | **快線 (MA7)** | 最近 7 天均價，反應最快，短期敏感指標。 |
| 🔵 **藍色通道** | **布林通道** | 就像股價的「合理波動範圍」，超出通道代表股價走極端。中間那條亮藍線是「中軌」，也是多空分界的參考。 |

## 二、什麼是「鬼爪」？

當股票開始走下跌趨勢的時候，你會看到黃色持股線下方冒出兩條線往下展開，就像一隻爪子張開一樣，我們叫它「鬼爪」。

```text
📈 [這裡是 K 棒]
       🟡——————————————  ← 持股線 (黃)
         🟠﹨                ← 中繼鬼爪 (橘黃) 開始張開
           🟢﹨﹨            ← 外層鬼爪 (螢綠) 張得更大
              ﹨﹨﹨
```

*   **爪子張開** = 跌勢來了，要小心！
*   **爪子收斂閉合** = 跌勢趨緩，止跌訊號。

## 三、V3 新功能：右下角智能面板

V3 版本在圖表右下角會出現一個小面板，幫你即時確認當下市場狀況：

| 面板欄位 | 說明 |
| :--- | :--- |
| **Mode** | 🟠 Auto = 智能辨識中；灰色 Manual = 手動模式 |
| **Asset** | 當前偵測到的商品類別（如：台股個股、台指期貨、加密貨幣...）|
| **MA88 Bias** | 🟢 綠色 = 負乖離（可能超跌）；🔴 紅色 = 正乖離（可能追高）；白色 = 正常範圍 |
| **MFI Vol** | 🟢 綠色 = 買盤主導（量能強）；🔴 紅色 = 買盤不足（量能弱）|
| **ADX Trend** | 🟢 綠色 = 趨勢行情；灰色 = 盤整警示（此時圖示會變半透明）|
| **Trend** | 🟢 Bullish = 多頭排列；🔴 Bearish = 空頭 |

> [!NOTE]
> 當 ADX 顯示灰色（盤整期），所有進場訊號圖示會自動變成半透明。這不是錯誤，代表「市場沒有方向感，建議少動或不動」。

## 四、V3 六大進場訊號說明

圖表上會自動出現符號，V3 版本有六種圖案，用**形狀**就能判斷強弱，不需要依賴顏色深淺！

### 🐣 一般藍鳥 (小量試單)
*   **出現時機**：MACD 動能剛從負轉正，大趨勢向上，站上布林中軌。
*   **強度**：一般。建議**小量試單**（1~2 成部位），等後續訊號確認。
*   💡 **白話版**：感覺要開始漲了，可以先買一點點看看。

### 🐦 強力藍鳥 (積極試單)
*   **出現時機**：同一般藍鳥，但**股價還在 MA88 下方很深的位置**（超跌）。
*   **強度**：強！橡皮筋效應最強，超跌反彈的最佳買點之一。
*   💡 **白話版**：跌太多了！彈回來的力道會更大，可以比較積極買。

### ✈️ 弱火箭 (輕倉觀察)
*   **出現時機**：黃色持股線向上突破桃紅多空線，MACD 也在正區間，**但成交量不夠強**（MFI 未超標）。
*   **強度**：偏弱，需觀察。等量能跟進才加碼。
*   💡 **白話版**：方向對了，但力氣不夠，先買一點但不要全壓。

### 🚀 強火箭 (正式建倉)
*   **出現時機**：同弱火箭，但同時**成交量大幅跟進**（MFI 超過強勢門檻）。
*   **強度**：最強！量價齊揚，是最有信心的進場訊號。
*   💡 **白話版**：方向對、量能又配合，大膽進場！

## 五、出場訊號說明

### 💰 錢袋 (減碼落袋)
*   **出現時機**：MACD 紅柱已連續縮小，代表上漲動能開始衰退（但還沒轉空）。
*   **適合做什麼**：賣出**部分**持股（建議 1/3 到 1/2），先把利潤落袋。
*   **最多出現幾次**：正常行情 2 次，強勢趨勢（ADX > 25）最多 3 次。
*   💡 **白話版**：上漲力道開始變弱了，先賣一半出來，不要太貪心！

### ⚠️ 警告 (全數出清)
*   **出現時機**：MACD 死叉（從正轉負）**且**股價同時跌破布林中軌。**雙重確認**，比 V2 版本更精準，不容易被假訊號洗出場。
*   **適合做什麼**：**全數清倉**，結束這波交易。
*   💡 **白話版**：不對勁了，趕快全部賣掉！

## 六、完整操作流程（圖示版）

```
Step 1：看持股線 (黃) 是否在多空線 (桃紅) 的上方
  ├─ 是 → 大趨勢向多，可以考慮做多
  └─ 否 → 大趨勢向空，不建議買進

Step 2：等待進場訊號
  ├─ 出現 🐣 一般藍鳥 → 小量試單（1~2 成）
  ├─ 出現 🐦 強力藍鳥 → 積極試單（2~3 成）
  ├─ 出現 ✈️ 弱火箭   → 方向確認，但量能弱，輕倉（2 成）
  └─ 出現 🚀 強火箭   → 量價齊揚，正式加碼（3~5 成）

Step 3：持有過程中
  ├─ 出現 💰 錢袋   → 賣出 1/3 ~ 1/2（可能出現 2~3 次）
  └─ 鬼爪開始張開  → 提高警覺，準備防守

Step 4：出場
  └─ 出現 ⚠️ 警告  → 全部賣出，這波結束

⚠️ 特別注意：ADX 面板顯示灰色（盤整期）時，圖示會半透明，建議降低出手頻率。
```

## 八、常見問題 (Q&A)

*   **Q：鬼爪出現就要賣嗎？**
    *   A：不一定！鬼爪是「跌勢警示」，要配合 ⚠️ 警告訊號（MACD 死叉 + 跌破布林中軌）才是真正的出場時機。V3 版本的警告訊號要求雙重條件同時成立，所以比 V2 更可靠。
*   **Q：面板的訊號半透明是壞事嗎？**
    *   A：不是壞事，是提醒你。這代表 ADX 偵測到現在是盤整行情，這種時候訊號準確度較低，建議少動或不動。
*   **Q：弱火箭和強火箭有什麼實際差別？**
    *   A：強火箭代表「主力資金同步進場」（MFI 高量），成功率明顯更高。弱火箭是「方向轉對了，但還沒有大資金跟進」，需要等待量能確認後再加碼。
*   **Q：一般藍鳥和強力藍鳥什麼時候更好用？**
    *   A：強力藍鳥出現代表股價已在相對低位（對 MA88 的負乖離很大），上方空間更充裕，是「左側交易者」最愛的買點。一般藍鳥也不錯，只是反彈空間可能稍小。
*   **Q：沒有出現任何訊號，我可以自己買嗎？**
    *   A：這套系統設計上是「等訊號再動作」，沒訊號代表時機未到，耐心等待是最好策略。
