> **適用版本**：`ghost_claws_v4.1.pine`
> **最後更新**：2026-05-13
> **前置需求**：已閱讀 V4.0 使用手冊，了解基本的六大訊號與面板操作。

## 🚀 V4.1 新增了什麼？

V4.1 是在 V4.0 穩定架構的基礎上，針對**海外期貨交易者**與**多元商品持有者**的需求所做的精準升級，主要分三大方向：

| 升級方向 | 具體改變 |
|----------|----------|
| 📡 **Telegram 警報品質** | 加入 MTF 四時框趨勢、防守價位、精準台灣時間 |
| 🌐 **AI Router 覆蓋範圍** | 從 16 種分類擴充至 25+ 種，填補所有漏網之魚 |
| 🐛 **Bug 修正** | 棉花死碼、TMF 誤歸類、缺少 Tooltip |

## 一、MTF 多時框趨勢警報（核心新功能）

### 這是什麼？

每當 JJ 鬼爪觸發任何訊號（藍鳥、火箭、動能再啟、錢袋、警告），系統會**自動在 Telegram 訊息中附上四個關鍵週期的多空狀態**，讓你不必手動切換圖表，就能立刻判斷大局。

### 範例 Telegram 訊息（V4.1）

```
🚀 JJ 鬼爪 - 強火箭 Strong Rocket!
商品：TXF1! TAIEX FUTURES 🇹🇼 | 週期：240

MTF 趨勢：1W🟢 | 1D🟢 | 4H🟢 | 1H🔴

訊號價位：21,450
防守價位：21,235 (MA17短波段) / 20,880 (MA88長波段)

MA17 穿越 MA88 ✅ | MACD > 0 ✅
乖離率：2.35%
量能：帶量突破 ✅（MFI 67.2）
建議：正式建立波段部位

⏰ 2026-05-13 14:35 (台灣時間)
```

### 如何解讀 MTF 趨勢？

| 組合 | 解讀 | 操作建議 |
|------|------|----------|
| 1W🔴 1D🔴 4H🔴 1H🔴 | 全線多頭 | 最強進場訊號，可積極建倉 |
| 1W🔴 1D🔴 4H🔴 1H🟢 | 大多小回 | 短期拉回中，仍可建倉，停損縮緊 |
| 1W🔴 1D🔴 4H🟢 1H🟢 | 大多，中期整理 | 等待 4H 翻多確認後再入場 |
| 1W🔴 1D🟢 4H🟢 1H🟢 | 週線多，但可能大整理 | 謹慎，等待日線翻多 |
| 1W🟢 1D🟢 _ _ | 主趨勢空頭 | 本指標訊號可靠性大降，停用自動入場 |

> [!TIP]
> **MTF 只出現在 Telegram 警報中，不佔用圖表版面。** 這是刻意的設計，讓你的 TradingView 畫面保持乾淨。
>
> ⚠️ **顏色慣例**：本指標採用台灣慣例，🔴 紅色 = 多頭，🟢 綠色 = 空頭。面板的「Trend」欄位顯示紅色代表多頭，與 TradingView 預設顏色相反，請留意。

## 二、防守價位入報

每則警報都會自動計算並附上當前 K 棒的三個關鍵價位：

| 資訊欄 | 說明 | 用法 |
|--------|------|------|
| **訊號價位** | 訊號觸發當下的收盤價 | 作為進場參考基準 |
| **MA17（短波段防守）** | 當前 MA17 的值 | 跌破此價，短波段失守，考慮減碼 |
| **MA88（長波段防守）** | 當前 MA88 的值 | 跌破此價，多頭環境結束，清倉 |

> [!IMPORTANT]
> 你可以在收到 Telegram 警報後，直接把防守價位填入 TradingView 的停損單，**無需再切回圖表確認價格**。

---

## 三、台灣時間精準化

V4.1 前的版本，警報的時間欄位有時會顯示 UTC 時間或格式不穩定。V4.1 採用與 **5K 戰法**相同的時間函數：

```pine
str.format_time(timenow, "yyyy-MM-dd HH:mm", "UTC+8")
```

現在每則警報的時間欄位都是 **100% 正確的台灣時間（UTC+8）**，格式如：`2026-05-13 14:35`

## 五、操作建議（承接 V4.0）

### 快速決策流程（每次收到 Telegram 警報時）

```
1. 看 MTF 趨勢欄 → 確認大局是否多頭一致
2. 看訊號類型（藍鳥/火箭/動能再啟）→ 決定倉位大小
3. 看防守價位（MA17/MA88）→ 決定停損位
4. 看面板 Asset 欄 → 確認指標使用正確參數
5. 看面板 Strength 欄 → 決定抱到哪裡減碼
```

### 訊號強度與倉位建議

| 訊號 | MTF 建議 | 倉位 | 防守 |
|------|----------|------|------|
| 🐣 一般藍鳥 | 1D 多頭（🔴）即可 | 小量試單 | 以 MA88 為停損 |
| 🐦 強力藍鳥 | 1D+4H 皆多頭（🔴🔴）| 3~5 成 | 以 MA88 為停損 |
| ✈️ 弱火箭 | 1D 多頭（🔴）即可 | 輕倉觀察 | 以 MA88 為停損 |
| 🚀 強火箭 | 1D+4H 皆多頭（🔴🔴）| 5~7 成 | 以 MA17 為停損 |
| ⚡ 動能再啟 | 1D 多頭（🔴）即可 | 補回前波減碼 | 以 MA7 為停損 |
| 🛸 強力動能再啟 | 1D+4H 皆多頭（🔴🔴）| 積極補倉 | 以 MA7 為停損 |
| 💰 錢袋 | — | 減碼 1/3~1/2 | — |
| ⚠️ 警告 | — | 全數清倉 | — |

### 加密貨幣與天然氣的特別設定

這兩類商品的波動率遠超一般商品，使用時建議調整：
1. 進入「**鬼爪特效**」設定群組
2. 將「中繼鬼爪張力倍數」從 0.6 調至 **1.0**
3. 將「外層鬼爪張力倍數」從 1.2 調至 **1.8**
4. 同時，智能模式會自動套用更寬鬆的 bias（加密 20%，天然氣 12%）

## 六、Telegram 警報設定指南

### 設定步驟

1. 在 TradingView 打開你要監控的商品
2. 確認圖表已掛載 `JJ 鬼爪 V4.1` 指標
3. 點擊「**快訊**」→「新增快訊」
4. **條件欄**：選擇「JJ 鬼爪 V4.1」→「任一警報觸發」（或選擇特定訊號）
5. **通知欄**：勾選「Webhook URL」
6. **Webhook URL**：填入 GAS 部署網址（詳見 `Telegram_Credentials.md`）
7. **訊息欄**：留空（訊息由程式碼自動生成）
8. 儲存快訊

> [!WARNING]
> 每次在 TradingView 修改並重新儲存指標後，**警報不需要重新建立**，但建議確認 Webhook URL 仍然有效（GAS 若重新部署 URL 可能會變更）。
