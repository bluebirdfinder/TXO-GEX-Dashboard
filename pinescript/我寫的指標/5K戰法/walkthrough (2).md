# 5K戰法 V2 智能升級展示

在本次升級中，我們將「5K戰法」推向了真正的專業化，實作了跨商品的**自動參數切換引擎**。

## 🌟 核心升級亮點

### 1. 智能商品辨識 (Auto-Detect Engine)
現在，指標會自動讀取你圖表上的商品代碼 (`syminfo.root`)，並且涵蓋了以下類別的所有常見合約（包含原型、小型、微型）：
- **台股/美股指數**：包含你特別要求的**富時台灣指數 (TWN)**。
- **國際指數**：日經、德指、恆生。
- **金屬與原油**：黃金、白銀、銅、原油、天然氣。
- **農產品**：黃豆、玉米、小麥、棉花。
- **外匯期貨**：歐、英、澳、日幣等。

### 2. 參數自動最佳化
當切換到不同商品時，指標會在背後默默幫你把這三個最關鍵的參數調整到最佳狀態（基於我們稍早產出的分析報告）：
- **急殺/急拉 ATR 乘數**
- **快速停利風報比**
- **回溯區間 (Lookback Bars)**

> [!TIP]
> 當然，我也保留了完全的控制權給你。在設定面板的最上方有一個「**智能模式 (Smart Mode)**」開關。如果你想自己手動調參數做實驗，只要把開關關掉，指標就會退回吃你手動輸入的數字。

### 3. 修復隱藏 Bug (ta.highest)
在檢查 V1 的過程中，我發現了一個隱藏的 Bug：雖然設定面版有 `lookback_bars` 的輸入欄位，但過去的程式碼其實**寫死了 10 根 K 棒**。在 V2 中，這個問題已經徹底修復，現在會確實且動態地讀取 48、60 或 72 根的回溯區間。

### 4. Dashboard 面板強化
為了讓你在交易時感到安心，右下角的 Dashboard 新增了兩欄重要資訊：
- **Mode (模式)**：顯示目前是 `Auto (智能)` 還是 `Manual (手動)`。
- **Asset (資產)**：顯示程式目前辨識出這是什麼商品（例如：切到 NQ 時會顯示 `US Index (Volatile)`）。
